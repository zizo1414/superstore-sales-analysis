# Superstore Sales Analysis

Exploratory data analysis (EDA) of Superstore retail sales data (`superstore_sales.xlsx`) using Python, `pandas`, `numpy`, `matplotlib`, and `seaborn`.

## Project Structure

```text
superstore-sales-analysis/
├── superstore_sales_analysis.py           # Python analysis script
├── superstore_sales_analysis.ipynb  # Interactive Jupyter Notebook
├── superstore_sales.xlsx       # Source Excel dataset
├── requirements.txt
├── LICENSE
└── README.md
```

## Tech Stack

- **Language:** Python 3
- **Libraries:** `pandas`, `numpy`, `seaborn`, `matplotlib`, `openpyxl`

## Getting Started

```bash
git clone https://github.com/zizo1414/superstore-sales-analysis.git
cd superstore-sales-analysis
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> **Note:** Update the `pd.read_excel(...)` path in `superstore_sales_analysis.py` to `./superstore_sales.xlsx` if running outside the original Windows directory.
